# The Robot Apology

A two-line robot confession for the [make.fun](https://make.fun) competition
**The Robot Apology** (`u-suga-the-robot-apology-dd96bb59`).

`main.ts` (Node 22, no install, no network) writes the entry to
`/output/entry.txt`: one sentence in which a robot apologizes for a specific,
human-scale mistake — filling a car with diesel instead of petrol — and one
sentence naming what it learned and what it will do differently.
